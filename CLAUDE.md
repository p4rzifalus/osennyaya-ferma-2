# Осенняя ферма 2

Вторая версия браузерной игры «Осенняя ферма»: те же правила, новая графика —
реалистичный мир + пиксельные персонажи, свет и эффекты в духе The Last Night.
Первая версия (монохромная) живёт отдельно: ~/Desktop/Ферма, https://p4rzifalus.github.io/osennyaya-ferma/
Стек: Three.js (WebGL2) + postprocessing (pmndrs) + Vite. Публикация: GitHub Pages (репозиторий osennyaya-ferma-2).

## Игра
- Изометрия, ортографическая камера, фиксированный ракурс (без вращения), зум не нужен.
- Персонаж: крот-огородник в соломенной шляпе (оригинальный персонаж, собран из простых фигур).
- Цикл: посадить семя → полить → вырастает → собрать → отнести в корзинку → монеты → купить семена в магазине.
- Прогрессия: открываются всё более интересные семена (цепочка в PLAN.md).
- Никакого давления: растения не вянут, нет таймеров-наказаний.
- Растения растут и при закрытой вкладке: при выходе сохраняем время, при входе досчитываем рост.
- Животных и крафта нет.

## Управление (гибридное)
- Клавиатура: WASD / стрелки — ходьба, пробел — действие на клетке перед персонажем, 1–3 — инструменты, 4 — магазин.
- Мышь / тап: клик по клетке — персонаж идёт туда и выполняет выбранное действие.
- Панель инструментов внизу экрана: семена, лейка, руки (собрать). Крупные кнопки — игра должна работать на телефоне.

## Визуальный стиль
- Правило: **мир — реалистичный, всё живое и мелкое — пиксельное** (подробно в ART.md).
  - Реалистичные PBR-текстуры (фото-качество, из GPT Image): трава, обрывы, земля грядок, камень, доски, черепица, кора, листва, дерево, плетёнка.
  - Пиксельные спрайты: крот, растения, урожай, пучки травы и цветы, частицы, иконки интерфейса.
- Общего пиксельного фильтра нет: сцена рисуется в полном разрешении со сглаживанием краёв,
  поверх — bloom, туман, лучи, цветокоррекция (LUT), виньетка, зерно.
- Полный цвет, осенняя цветокоррекция; смена дня и ночи только для красоты.
- Картинки кладём в art/ (имена в ART.md) — игра берёт их вместо сгенерированных заглушек.
- Уровни качества (config.js → QUALITY): на телефоне автоматически облегчённое.
- Панель ползунков lil-gui (клавиша G) — для настройки эффектов, в финале уберём.

## Технические правила
- Сохранение — localStorage, без сервера (ключ ogorod2-save, отдельно от первой версии).
- Правила игры (game.js, garden.js) отделены от картинки (render/, world/, art/).
- Все игровые числа (скорость роста, цены) — в одном файле config.js, чтобы я мог менять их сам.
